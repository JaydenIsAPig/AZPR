# Legacy Documentation

This directory stores superseded versions of the five current document families. It is empty at v1.0 because no prior governed current version existed.

Use these subdirectories when the first replacement occurs:

```text
docs/legacy/
├── project-structure/
├── backend-structure/
├── business-logic/
├── business-data/
└── frontend-design/
```

Archived files must be marked `document_status: superseded` and must never be treated as current authority.
