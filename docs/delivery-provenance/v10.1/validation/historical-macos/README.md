# Historical macOS validation diagnostics

These files preserve the earlier macOS ARM64 verifier and dependency evidence
byte-for-byte. They are superseded diagnostic provenance, not the active
delivery-verifier result and not deletion candidates.

The failures document why Linux `/proc`, `/home/oai`, and subprocess behavior
had to be reproduced on a Linux reviewer runtime. The active pre-qualification
evidence is one directory above. Neither evidence set is a formal audit or
controller-activation authority.
