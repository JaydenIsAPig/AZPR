# AZPR v8 Canonical-Policy Gate

V8 does not ship or approve an active canonical policy. The governing DOCX hash remains the future authority. Independent consultation verified that the retained supported-OOXML renderer preserves all 227 source units, 276 Word tabs, and 19 explicit line breaks in the supplied Master Operating Prompt, with no unsupported normative parts detected.

That extraction result is implementation evidence, not approval.

V8 introduces two installation phases:

- `QUALIFICATION_ONLY`: canonical-policy derivatives are forbidden, and all production launchers fail closed.
- `POLICY_ACTIVATED`: exact canonical text, source manifest, section map and independently signed record are required and must be separately authorized.

Activation requires visual comparison against Word/PDF, exact hash review, distinct policy-owner and security-approver signatures, and a new one-use installation authorization bound to the exact record. Prompt 004 remains blocked until that phase is independently approved.
