# AZPR v10.1 Evidence Derivation and Key Lifecycle Integration Report

Machine-derived evidence remains authoritative over signed summary claims. Contradictory, incomplete, stale, irrelevant, or mismatched PASS data fails. Probe evidence now also depends on the anchor-verified host authority, exact signed policy, independently signed service attestation, actual executable identity, key validity, and revocation chronology.

Atomic key-lifecycle epoch, rollback detection, recovery state, and stale-key rejection controls are preserved. Real custody ceremonies and integration with production HSM/anchor consumers remain unperformed.
